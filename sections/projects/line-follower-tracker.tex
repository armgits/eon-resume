\begin{project}
  {Vision-based Line Follower Robot Tracker}
  {From Faculty Assistant position at ISR}
  {Jan 2024 - Present}
  {https://github.com/ENEE467/line-follower-tracker}

  \item Developed an application to measure position and deviation of line following robots
        using fiducial markers and a camera.

  \item Written object-oriented modern C++ code, utilized OpenCV, Matplot++ and ImGui libraries for
        implementation.

  \item Implemented 3D frame transformations and calculations for finding the shortest distance from
        various 2D shapes.

  \item Dockerized the development environment, automated dependency installations and compilation
        with a shell script.

\end{project}
